API Usage Guide

1. Generate Email

POST /api/v1/generate
Header: X-API-Key: YOUR_KEY
Body: {"domain": "beking.online"}  // or "random"

Response: {
  "ok": true,
  "created": [{"email": "abc@beking.online", "token": "ABCD1234"}]
}

2. Check Inbox & Get OTP

POST /api/v1/inbox
Header: X-API-Key: YOUR_KEY
Body: {"token": "ABCD1234", "wait": 30}  // wait up to 30s

Response: {
  "ok": true,
  "email": "abc@beking.online",
  "otp": "980272",
  "emails": [{"sender":"...", "subject":"...", ...}]
}
